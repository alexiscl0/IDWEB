W3C

¿Que es el W3c?

Es un conjunto de reglas, recomendaciones y especificaciones técnicas que la World Wide Web Consortium (W3C) desarrolla para que las tecnologías de la Web funcionen de manera compatible, accesible y consistente.

¿Para que sirve?

  1. Compatibilidad
  2. Acesibilidad
  3. Buenas Practicas
  4. Interoperabilidad
  5. Evolucion de la WEB
