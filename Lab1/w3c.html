W3C

¿Que es el W3c?

Es un conjunto de reglas, recomendaciones y especificaciones técnicas que la World Wide Web Consortium (W3C) desarrolla para que las tecnologías de la Web funcionen de manera compatible, accesible y consistente.

¿Para que sirve?

  1. Compatibilidad
  2. Acesibilidad
  3. Buenas Practicas
  4. Interoperabilidad
  5. Evolucion de la WEB

Esatandar W3c: PNG

¿Que es el PNG?

PNG (Portable Network Graphics) es un formato de imagen desarrollado como un estándar abierto para almacenar y transmitir imágenes digitales. La especificación de PNG fue estandarizada por el W3C.

Caracteristicas Principales

  1. Permite imgenes de alta calidad
  2. Utiliza la comprension sin perdida
  3. Es ampliamente utilizado en sitios web
  4. Permite transparencia, incluso mediante un canal alfa
  5. Gneralmente archivo más grandes que JPEG
